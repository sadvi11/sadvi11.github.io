Notes

Working notes on retrieval, agents and production AI. Every one is written from something I built — and most of them exist because I got it wrong first and had to find out why.

I keep these because writing an explanation is the fastest way to discover I did not understand something. If they are useful to anyone else, that is a bonus rather than the point.

Things I got wrong

The most useful notes. Each one is a bug that produced no error message.

A comment that described code I had not written

The docstring said the blocking call was dispatched to a thread so it would not hold the event loop. It was not. The results were identical, the tests passed, and the concurrency simply never happened.

The tests that were lying to me

I had ninety-one passing tests and I felt safe. Three of them were protecting nothing at all, and the only way I found out was by breaking my own code on purpose.

The chunk that inherited the wrong heading

A short section fell below my minimum chunk size, merged backwards into the section before it, and took that section's heading with it. It then embedded under the wrong topic and became unreachable by anyone asking about it. Nothing errored.

Retrieval

Why hybrid search, and how rank fusion actually works

A good embedding model cannot reliably find RTN-14. Keyword search cannot find a paraphrase. The interesting part is not running both — it is that you cannot add their scores together, and what you do instead.
