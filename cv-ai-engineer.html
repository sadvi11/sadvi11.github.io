Selected AI Engineering Work

All public and independently verifiable at github.com/sadvi11. Every repository passes automated tests on every change.

MCP tool server with policy enforced in code - terraform-guard-mcp

A Model Context Protocol server exposing five tools to any MCP client, verified end to end against a live client: full handshake, tool discovery, and invocation. Its decision tool returns a verdict computed in Python, not by the model, so no wording in the input can argue it down — including a test case whose payload is named to look pre-approved and contains an instruction to ignore prior instructions. 34 tests; the pipeline removes each of three guards on purpose and fails if the suite still passes. Then I attacked my own tool and found a prompt-injection weakness in it: attacker-controlled text was printed into the model-facing output, able to forge a false system boundary. Fixed at parse time so all five tools are covered, with tests asserting structure rather than vocabulary.

Anti-hallucination and evaluation - bedrock-agentcore-customer-agent

A customer support agent on Amazon Bedrock AgentCore. Retrieval returns the best match and its similarity score; below an explicit floor the agent returns NO_CONFIDENT_MATCH with the score and threshold and escalates to a human rather than answering from a weak match. Evaluation runs against 40 held-out questions scoring both correct answers and correct refusals. Found that the confidence floor is model-specific and had to be re-measured when the embedding model changed — carrying the old value across would have refused roughly half the answerable questions.

Retrieval-augmented generation on Bedrock - bedrock-rag-app

Document question answering: extraction, chunking with overlap, Titan Embeddings V2 at 1024 dimensions, vector search over pgvector, and grounded generation that reports missing context instead of inventing an answer. Deployed and live. Data residency limitations documented explicitly rather than glossed over.

Structured output and guardrails - structured-test-agent, smart-ai-agent, aws-ec2-read-only-agent

Forced tool choice against a strict JSON Schema so responses are machine-consumable by construction, with tests asserting the schema stays strict rather than advisory. An agent with tool use and persistent vector memory, graded by an evaluation suite that attacks it with prompt injection and SQL injection.
